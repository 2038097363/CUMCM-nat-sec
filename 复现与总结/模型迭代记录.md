# 模型迭代记录

下列名称是研发时的记录编号，本表侧重各轮改动和去向；测试数据集中见[测试结果总览](测试结果总览.md)，关键取舍的原因见[典型案例](典型案例_从现象到决策.md)。不同轮次使用的场景与评价口径可能不同，数字不能直接跨批次比较；“留出”均指当时保存的本地合成场景。最终第三问选 CCR-JS（历史 round7），第四问选 VC-SVS（历史 round12/no_probe）。

| 阶段 | 核心改动与选择 |
|---|---|
| 基础与第 1—2 轮 | 建立测向集合、保证接收和覆盖证书，比较联合调度、负反馈、先扫描等方向；逐步分离发现保证与时间优化。详见 `问题/历史研究/题目分析_全轮次归档.md`。 |
| 第 3—4 轮 | 第三问采用剩余覆盖路线，第四问比较调度与矩形光学后备；各有更慢案例，round4 后来作为稳健对照。详见 `问题/问题3/第三轮改进与验证.md`、`第四轮模型探索.md`。 |
| 第 5—6 轮 | 探索外圈连续巡航、负观测利用和定向状态区间；第三问部分候选收益较小，第四问探索定向朝向约束。详见 `问题/问题3/第五轮环路与联合状态探索.md` 和 `第六轮候选决策与验证.md`。 |
| 第 7 轮早期候选 | 第三问探索增加环站、非对称布局和补扫；最优冻结组合在108例上平均提速2.10%，低于预设3%门槛，未接入。详见 `问题/问题3/第七轮优化结果.md`。它与下方后来发布的 round7 不是同一候选。 |
| 第 7 版最终选型 | 在早期候选未达门槛后，引入队内第三问方案，结合连续扫描区域和联合路径，最终定为 CCR-JS；108 个配对合成场景平均从 251.19 降至 232.21 秒/源，仍有退步场景。详见 `问题/问题3/round7学习融合与发布验证.md`。 |
| 第 8 轮 | 第四问尝试状态价值选点，合成结果改善，但三次演练表现不理想，失败清除增多，未作为最终版本。详见 `问题/问题4/round8联合状态选点与验证.md`。 |
| 第 9 轮 | 扩展联合状态与调度方案；平均收益存在，但单例退步超过预设门槛，未发布。详见 `问题/问题4/round9重构与验证.md`。 |
| 第 10 轮 | 较激进的动态调度与局部处理在合成场景平均提速，但存在明显反例；队员要求恢复并做 10 次演练，全部清除，促使继续研究。详见 `问题/问题4/round10动态调度与有界探查.md`、`round10同场退步原因.md`。 |
| 第 11 轮 | 探索基于证明的光学点剪枝，以减少已知无效动作；演练样本未触发剪枝收益。详见 `问题/问题4/round11证明型剪枝.md`。 |
| 第 12 轮 | 对第 10 轮反例研究局部费用与基线融合，多个候选缺乏稳定收益；最终采用 no_probe，取消不承担完成性义务的末源额外探查。522 个冻结场景全清；**相对第10轮**13 例更快、509 例相同。详见 `问题/问题4/round12/round12测试结论.md`。 |
| 第四问思路回迁第三问 | 针对round7比较分支测向、信号风险和局部任务衔接；冻结的任务衔接候选在498例有小幅平均收益但也有41例退步，最终保持round7。详见 `问题/问题3/第四问思路迁移/与round7对比结论.md`。 |

正式结果与上述开发/演练数据分开：问题三、四各三次正式测试的数据在 `输出/正式测试/`，最终论文中的平均值以正式结果为准。
