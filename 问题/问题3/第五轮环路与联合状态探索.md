# 第五轮：环路顺序与联合状态探索

> 历史实验：下文round5选型和测试状态属于当时阶段，不能作为最终策略或正式测试状态。第三、四问最终选型见[论文](../../论文/B题论文_正式测试最终稿.pdf)。

本轮由用户外圈遍历建议及附件触发。round4的两问各3次官方演练、源码指纹和全部离线结果保留为基准。研究仅使用本地合成场景；正式测试禁止。新的候选先开发、后冻结，再使用新留出，不以开发成绩自动替换运行入口。

## 提议与现有实现的区别

- 第三问已有中心加外圈六点、逐频道负观测账本及连续删站证书。原路线也使用最近邻加2-opt，不是任意跳点。新比较关注环上顺序是否应当保留、允许插入任务后从哪个后续站接回。
- 第四问已有中心、半径999米的内圈8站、半径约1866.50米的外圈12站。区域外补盲已使用且有连续证书，本轮先固定布局，分离访问顺序的影响。
- 第二问已有目标圆域下任意首测的连续接收判据。850、534.68只是原点首测示例。任意首测的优选算法及精度约束下的短程选择可继续扩展，但不能把原点全局误差界移植过去。
- 两步代价、成本试探、六角格及自由朝向矩形此前已有开发对照，不能因名称合理便直接启用。同点重复测向不减少固定误差；无信号还受未知半径影响。

## 候选及证据要求

1. 环路保持：初始选择顺/逆时针及入口，沿此顺序访问尚未取消的站，仍允许插入定位和清除。
2. 环路重选：每次从当前位置比较环序入口及方向；第四问比较内外圈分层路线和原2-opt路线。
3. 插入成本：把局部任务看作去下一站之前的绕路，估计增加的移动代价；并不强制返回离开的站点。
4. 第四问联合位置、半径与朝向：以连续方向区间的外包约束保留全部相容位置，必须同时保留全向源分支。负观测只有在该候选区域内保证处于最小相容接收半径时才能变成背向约束；无法证明则保留，不硬删。

所有新候选必须保持真值、合法动作、正确计时和完整终止。第三问删站仍逐频道独立核验；第四问保持21站或16源数量上限兜底。本轮先比较开发种子1008—1043，选择少量候选；新留出预留108000—108107。启用门槛为全部清除、几何/成本/边界核验通过且相对round4的配对平均节省95%重采样区间下限大于0。若均未通过，保留round4。案例不同的官方演练不作严格配对收益证据。

## 正确性检查和接入

140个额外压力案例覆盖10—16源、圆心/999米/1800米边界、最小接收半径1000米、定向前后和切线两侧、正负极端误差，全部清除。每次位置域更新由隔离的审计回调检查真实源仍被包含；策略本身只收到合法模拟反馈。第三问删站和不存在判定额外通过连续区域证书复核，所有计时分项与总时间核对。

41项关键测试通过，新增检查包括保留全向分支、远距离无信号不强制背向、正观测抬高半径下界、连续方向区间边界以及环路不丢站。有限测试不等于连续空间穷举；外包的数学包含关系是机制保证，当前实现仍采用带余量浮点计算，未作有向舍入形式化验证。

发布选择为round5：第三问算法不变，第四问在原21站＋观测复用＋矩形光学后备上加入64方向区间联合状态。统一入口仍为current_policy.py（原始资料未纳入本公开版），原运行命令不变。发布时另外做432次同种子接入回归，其中216次核对显式保留的round4基线、216次核对当前入口；它们只验证整合一致性，不增加独立性能样本量。完成状态见发布入口核验（原始资料未纳入本公开版）。

此前第三、四问各3次官方演练仍归属于round4，记录和指纹不变；round5本轮没有调用官方模拟器，正式测试使用次数为0。第四问新策略尚需单独记录3次演练，不能把round4成绩继承为新算法成绩。论文PDF与支撑包仍明确保留为round4冻结稿，本报告和第四问联合状态说明是第五轮新增材料，尚未混入旧论文。

## 对本次建议的最终取舍

1. **保留内外层覆盖思想**：第四问已使用区域外补盲；本轮验证顺序，未把21站重新解释成全在圆内的旧模型。
2. **不强制绕环**：相同扫描点的最短访问顺序，与穿插定位/清除后的最短总任务并不等价。第三问新留出没有支持替换原路线。
3. **采用联合状态约束**：真正新增的是把无信号在条件成立时用于定位，同时保留未知接收半径、全向类型及连续朝向。详细推导见第四问说明（原始资料未纳入本公开版）。
4. **未启用第四问动态删站**：已发现频道的位置/朝向收缩，不等于未发现频道也被排查。若要删站，必须给每个未知频道证明其全部位置—朝向可能性已被覆盖；不能照搬第三问1000米圆排除。
5. **不因复杂就叠加**：固定100米试探仍属可优化经验项，但此前成本试探未稳定胜出；两步前瞻、六边形清除格等历史结果保留。第二问任意首测的精度—移动权衡尚需另外冻结研究，未把第三四问环路结果当成第二问的改进。
