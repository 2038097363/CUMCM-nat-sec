# 本地可视化演示

双击 `启动演示.cmd`。程序会启动仅监听本机的服务并自动打开浏览器；关闭黑色服务窗口即可停止。若端口8765被占用，可在本目录运行 `python server.py --port 8766`。需要 Python 及项目的 NumPy、SciPy、Requests 等依赖；不确定环境时参见项目根目录 `requirements.txt`。

## 使用方式

选择问题三或四和场景种子，点击“生成并运行”；后台使用已有本地合成模拟器，页面按动作播放。种子决定合成场景，不是官方案例编码；目前源数量和位置随种子生成，界面不单独设置源数量。也可从下拉框选择已经保存的演练或正式动作记录回放；手输路径仅接受项目 `输出/` 下的 `.jsonl` 文件。

地图支持滚轮缩放、拖动和复位。勾选“教学视角”显示本地合成场景的源真值；勾选覆盖范围并点击源可查看其范围，点击空白恢复跟随当前动作。已清除源不再显示有效覆盖。回放保存的正式记录时没有真值，界面不会推测隐藏位置。右侧动作链可以滚动、点击跳转，底部支持播放、暂停、单步、进度拖动和倍速。

实时计算在后台进行，播放控制的是已产生事件的呈现，不会暂停后台策略，也不会改变虚拟时间。右侧费用按照题设规则从已播放动作重算；画面位置为动作停点，连线表示移动路径，不代表可沿途检测。

## 导入自己的策略

选择“加载自定义策略”，用文件选择器选择一个可信 `.py` 文件，或填写完整文件路径（二选一）。参照 `自定义策略示例.py`，文件应提供：

```python
def make_robot(backend, question):
    # 返回具有 run() 方法的策略对象
    return MyRobot(backend, question)
```

策略通过 `backend.post(path, position, channel)` 与本地环境交互，其中 path 为 `/enter`、`/measure`、`/clear`、`/exit`。参数及返回字段与项目内本地模拟器接口一致；不同于只返回单步动作的接口，已有策略如使用其他形式需要适配。文件选择适合单文件策略；需要额外文件或第三方库时，建议在自己的 Python 环境中准备依赖并使用完整路径，必要时自行设置模块导入路径。

**只运行你信任的策略文件**：自定义策略以普通本机 Python 代码执行，不是安全沙箱。教学真值由页面显示，不作为后端反馈提供给策略；不要通过其他方式读取模拟器内部真值来评估策略。

本工具独立于正常求解入口，使用本地合成后端，不连接官方模拟器；本地模拟器未证明与官方环境所有边界行为完全一致。若窗口无法启动，先在终端执行 `python server.py` 查看错误，检查依赖和端口；不要启动正式测试。
